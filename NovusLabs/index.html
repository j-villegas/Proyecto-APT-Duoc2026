Proceso

Del proceso al despliegue

El mismo orden en cada proyecto. Lo que se acuerda en el diagrama es lo que se prueba en el código.

  1. 01 / Definir

    Entender la operación

    Levantamos el proceso real con el cliente: quién contrata, quién planifica, quién ejecuta.

  2. 02 / Modelar

    Diagramas y datos

    BPMN, casos de uso y modelo entidad-relación antes de escribir la primera pantalla.

  3. 03 / Construir

    Iteraciones cortas

    Migraciones versionadas, panel y app avanzando juntos sobre el mismo esquema.

  4. 04 / Probar

    Plan de pruebas

    Pruebas unitarias, de base de datos y de flujo por rol, con un plan escrito.

  5. 05 / Entregar

    Despliegue y traspaso

    Documentación de arquitectura y operación para que el sistema siga vivo después.
